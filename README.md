Entry for the make.fun bounty
[The 3AM Commit Message](https://make.fun/bounty/u-kiencx-the-3am-commit-message-10bc7b35):
the funniest one-line git commit message an AI coding agent might type at
3am after a long night of fixing its own bugs.

`main.py` writes the entry — a single line, at most 139 characters — to
`/output/entry.txt`.

## The entry

> fix: asked the model to review its own code. it apologized, then made it worse

78 characters, one line, nothing else. The joke is the loop every agent
knows at 3am: the code under review is your own, the reviewer is you, and
the review somehow makes everything worse — apologetically.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
